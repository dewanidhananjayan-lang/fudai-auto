# 🎁 自动福袋助手（免 Root 安卓插件）

一个基于 **Android 无障碍服务（AccessibilityService）** 的自动参与直播间福袋工具。
不需要 Root、不需要 Xposed 框架，全部使用系统官方无障碍 API 实现自动化。

## 功能流程（与教程一一对应）

| 步骤 | 动作 | 实现方式 |
|------|------|----------|
| 第一步 | 自动点击直播间左上角的【福袋】悬浮挂件 | 查找文本/描述含"福袋"的控件并点击 |
| 第二步 | 在弹窗中自动点击【发表评论后参与】 | 查找该按钮控件并点击 |
| 第三步 | 自动填写评论并点击【发送】 | 若输入框为空则自动填入评论（可在代码中修改评论内容），再查找"发送"按钮点击 |
| 第四步 | 自动上滑切换到下一个直播间，循环参与 | 系统 `dispatchGesture` 手势 API 模拟上滑 |

内置状态机 + 超时保护：任何一步超过 12 秒未完成会自动重置流程，不会卡死。

## 使用方法

1. 将本项目编译成 APK 并安装到手机（编译方式见下文）。
2. 打开 App，点击 **"1️⃣ 打开无障碍设置"**，在系统设置中找到 **自动福袋助手** 并开启服务。
   （安卓会在弹窗提示"该服务可以查看屏幕内容"，这是无障碍服务的标准权限，本插件不联网、不收集任何数据）
3. 返回 App，点击 **"2️⃣ 开始自动参与福袋"**。
4. 打开任意直播间，插件会自动循环执行：点福袋 → 点参与 → 点发送 → 上滑切下一间。

## 编译 APK 的两种方式

### 方式一：GitHub Actions 云端打包（无需安装任何软件，推荐）

1. 在 GitHub 上新建一个仓库，把 `FudaiAuto` 文件夹里的所有文件上传上去。
2. 仓库会自动触发 `Build APK` 工作流；进入仓库的 **Actions** 页面，等构建完成后下载 `fudai-auto-apk` 产物，就是可安装的 `app-debug.apk`。

### 方式二：本地 Android Studio 打包

1. 用 Android Studio 打开 `FudaiAuto` 项目文件夹。
2. 等待 Gradle 同步完成后，点击菜单 `Build → Build Bundle(s)/APK(s) → Build APK(s)`。
3. 生成的 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`，传到手机安装即可。

## 自定义设置（都在 `FudaiService.kt` 顶部）

- `TICK_MS`：主循环频率（默认 1.2 秒）
- `SWIPE_DELAY`：发送评论后等多久上滑（默认 2.5 秒）
- `COMMENT_TEXTS`：评论内容候选池，可自由修改
- 若福袋挂件无法通过文本识别（个别版本界面控件无文字），可在 `findBagNode()` 中增加按屏幕坐标点击的兜底逻辑。

## ⚠️ 使用须知

- 本项目仅供学习和个人研究使用。自动发评论可能违反直播平台用户协议，**请控制频率、合理使用，账号被风控/禁言的风险需自行承担**。
- 不同版本 / 不同平台的直播间控件可能略有差异，如识别不到某个按钮，可参照上文自定义说明微调查找逻辑。
